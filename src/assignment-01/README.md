# Assignment 01 — Express Hello World

## Problem statement

Create a simple Express.js app which prints **"Hello World"**.

## Solution

A minimal Express server that responds with `Hello World` when you visit the root URL in a browser.

- **Framework:** Express.js  
- **Port:** `3000`  
- **Route:** `GET /` → returns `Hello World`  
- **Entry file:** `index.ts`  
- **Module system:** ES6 (`import` / `export`) with `"type": "module"` in `package.json`
